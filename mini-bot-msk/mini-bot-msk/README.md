# Mini Bot MSK – floating assistant app

Your MSK character floats over every screen. Tap him to see WhatsApp count, last notifications,
10-minute private notes, and reminders.

## Get the APK (no Android Studio needed)
1. On a computer, create a free GitHub repo and upload this whole folder (drag & drop works).
2. Open the repo's **Actions** tab -> **Build APK** -> **Run workflow**.
3. When it finishes (~4 min), open the run and download the **Mini-Bot-MSK-APK** artifact (a zip containing Mini-Bot-MSK.apk).
4. Send Mini-Bot-MSK.apk to your phone and install it (allow "install unknown apps" when asked).

## First run on the phone
1. Open Buddy -> tap **1** -> switch on "Allow display over other apps".
2. Tap **2** -> switch Buddy on in Notification access.
3. Tap **3** -> allow notifications and alarms.
4. Tap **Start Buddy on my screen**, then press Home. The character appears; drag it anywhere, tap it for the menu.

## Change the character
Replace app/src/main/res/drawable/buddy.png (keep the name buddy.png), rebuild.
